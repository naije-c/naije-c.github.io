硬件基础与GPIO

发表于2026-09-18|更新于2026-09-18|嵌入式开发

原理图和 PCB

  • 原理图：表示元件网络之间怎么连接
    • 用标准符号表示电阻、电容、芯片、电源、地等元件，并画出它们之间的电气连接关系

  • PCB：看“在实际电路板上怎么摆、怎么连”
    • PCB 是 Printed Circuit Board，印制电路板，也常叫印刷电路板 / 板子。
    • 在绝缘板上，通过铜箔走线、焊盘、过孔等，把原理图中的连接关系做成真实电路。

单片机

单片机可以理解为一台很小的电脑

  • CPU：按顺序执行我们写好的指令。
  • Flash：存放程序，断电后程序还在。
  • RAM：存放运行中的临时数据。
  • GPIO、定时器、串口等：和外部模块打交道。

以点灯为例

  • 先把程序烧录进去，芯片上电后执行指令。
  • 程序改变 GPIO 输出，进而控制 LED 的电流通路。
  • 同一套接线，可以改成闪烁、按键控制或定时亮灭。

VCC 和 GND

VCC

  • 电源标号，一般为 5V / 3.3V
  • 常用含义：正电源 / 供电端
  • 给芯片、模块和传感器供电

GND

  • 全称：Ground
  • 常用含义：0V 参考点 / 回流路径
  • 常见非隔离模块共地后，信号才有共同参考

VCC 的电压不是固定的

  • 51 单片机、许多传统模块：常见 5V
  • STM32：常见 3.3V，也写作 3V3
  • 同一系统里可能同时有 12V / 5V / 3V3

电平

高电平

  • 如接近 3.3V，通常读作 1

低电平

  • 如接近 0V，通常读作 0

模拟量：连续变化的量

数字量：更关注“0”还是“1”

不要把 VCC 和 GND 直接连在一起

发现短路立刻断电

GPIO

GPIO = General Purpose Input / Output，通用输入输出

GPIO 是单片机与外部世界交互的“门口”：
既可以输出信号，也可以读取外部状态
