C语言基础（2）

发表于2026-09-24|更新于2026-09-24|C语言基础

上一篇的程序只会输出一句我们提前写好的话，我们自己没办法参与进去

这一篇开始让程序动起来，我们给它数据，它算完再把结果告诉我们

下面三个小练习分别用到 int、char、float 三种类型，把输入输出的常用格式控制符过一遍

练习一：输入两个整数，输出它们的和

题目要求：定义 a、b、c 三个变量，输入 a 和 b，用 c 输出 a+b

完整代码

变量的声明

这一行的意思是：我要用三个变量，分别叫 a、b、c，它们都用来存整数

int 是 integer（整数）的缩写，是我们最常用的类型

一行里声明多个同类型的变量，变量名之间用英文逗号隔开就行，不用把 int 写三遍

变量可以理解成内存里的一小块空间，声明变量就是先跟系统打个招呼，让它给我们留出位置

类型决定这块空间能存什么、有多大，后面要学的 double、long long 也是同样的道理

输入

scanf 和上一篇的 printf 一样来自 stdio.h，它的作用是从键盘读入数据

%d 表示这次要读的是一个整数，我们有两个整数要读，所以写了两个 %d

& 是取地址符，scanf 需要知道数据具体放进哪个变量里，所以变量前面必须带上 &

两个数之间用空格或者回车隔开都可以，%d 会自动跳过中间的空白字符

计算与输出

= 在C语言里是赋值的意思：先算等号右边的 a + b，再把结果存进左边的 c

所以等号左边只能是一个变量，写成 a + b = c 是不合法的

这里的 %d 是一个占位符，输出的时候会被后面那个 c 的值替换掉

如果 c 里存的是 8，屏幕上就会打印出 8，然后换行

占位符和后面的参数要一一对应，有几个 %d 就要在后面给几个整数

如果写成 printf("%d %d\n", c); 这种参数不够的情况，程序会去读别处的数据，输出一串莫名其妙的数字

运行结果

比如输入 3 和 5，程序会输出

用 Dev-C++ 运行的时候，黑框里是不会有“输入：”这种提示的，那只是为了说明方便才写上去的

如果想让自己一眼看出该输入了，可以加一句 printf("请输入两个整数："); 但在提交到题库网站前要记得删掉，题库只认标准输出

易错点

忘记写 & ：scanf("%d %d", a, b); 这样编译器不会报错，但运行时会直接崩掉

分号依旧是英文分号，中文分号会被编译器当成无效字符

%d 只能读整数，如果输入了 3.5，它只会读到 3，小数点后面的部分会留在输入缓冲区里影响后面的读取

练习二：输入一个大写字母，输出对应的小写字母

题目要求：输入一个大写字母（char 类型），输出它对应的小写字母

完整代码

字符类型的变量

char 是 character（字符）的缩写，用来存单个字符

字符要写在单引号里，比如 'A'、'g'、'7'

单引号里只能放一个字符，'AB' 是不合法的

双引号括起来的是字符串，比如 "A"，它和 'A' 完全不是一回事，一个 char 变量也装不下字符串

为什么加 32 就能变小写

计算机里的字符其实都是用数字存的，这个数字叫 ASCII 码

  • 'A' 的 ASCII 码是 65，'B' 是 66，一直到 'Z' 是 90
  • 'a' 的 ASCII 码是 97，'b' 是 98，一直到 'z' 是 122

大写和小写这两段刚好相差 32

所以我们把大写字母的码值加上 32，得到的就是对应小写字母的码值

%c 表示以字符的形式输出

这里 c + 32 算出来其实是一个整数，但因为用的是 %c，printf 会把它当成对应的字符打印出来

如果写成 %d，输出的就是 ASCII 码本身，比如输入 G 会打印出 71

运行结果

另一种写法

其实标准库里已经帮我们准备好了这个功能，它在 ctype.h 这个头文件里

tolower 的作用就是把大写字母转成小写，如果传进去的本来就是小写或者其他字符，它会原样返回

两种写法都对，加 32 的方式更能帮我们理解字符和 ASCII 码的关系，读别人的代码时两种都要认识

易错点

如果这句 scanf 前面还读过数字，%c 会把上一次输入剩下的空格或者回车符读进去，程序看起来就像没等你输入就结束了

解决办法是在 %c 前面加一个空格，写成 scanf(" %c", &c); 这个空格的作用是跳过前面所有的空白字符

练习三：float 类型的输入和输出

题目要求：输入一个 float 类型的数，再把它输出

完整代码

浮点类型

float 是浮点类型，用来存带小数点的数，比如 3.14、0.5、-2.75

int 是存不下小数部分的，写 int x = 3.14; 只会得到 3

float 是单精度浮点数，占 4 个字节，能保证大约 7 位有效数字

如果对精度要求更高，就用 double（双精度，8 个字节）

格式控制符

输入和输出用的都是 %f，不过两边的要求不完全一样

  • scanf 读 float 必须用 %f；如果要读 double，必须写成 %lf
  • printf 里 float 和 double 都用 %f 就行，float 在传参时会自动提升成 double

默认情况下 %f 会输出 6 位小数

想控制小数位数，就在 f 前面加一个点和数字，比如 %.2f 表示保留两位小数

运行结果

如果把输出换成 printf("%.2f\n", x); 那结果就是 3.14

精度和整数除法

浮点数在计算机里大多数时候是近似存储的，像 0.1 这种十进制小数没办法用二进制精确表示

所以拿 float 算出来的结果去比较大小、判断是否等于某个值，经常会差一点点，这是正常的，不是你的代码写错了

还有一个非常经典的坑：整数除以整数，结果还是整数

printf("%f\n", 1 / 2); 会输出 0.000000，因为 1 和 2 都是整数，先算出了整数 0，再补上小数部分

想让结果是 0.5，就要让参与运算的数里至少有一个是小数，比如写成 1.0 / 2 或者 1 / 2.0

易错点

scanf("%f", &x) 里的 x 必须声明成 float，如果声明成 int，程序会读到错误的数据

%f 和 %lf 别写反，scanf 里写错不会报错，但拿到的数据是乱的

小结

三个练习用到的对应关系整理成一张表，以后写代码可以直接对照

类型 用来存什么 scanf 里用 printf 里用 例子
int 整数 %d %d 42
float 小数 %f %f / %.2f 3.14
double 精度更高的小数 %lf %f 3.1415926535
char 单个字符 %c %c 'A'

写的时候记住一句话：变量类型、格式控制符、参数个数，这三样必须对得上
