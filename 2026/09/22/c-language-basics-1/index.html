什么是C和编译器？

  • C是一种常见的编译型编程语言，有接近底层、效率高、可移植等特点。
  • 而编译器是负责将我们写的源代码翻译成目标代码，也就是让电脑能够看得懂、能执行。

学习工具

我们一般选择在IDE中对代码进行编写、编译运行。

Dev-C++就是新手最常用的IDE之一，特点是开箱即用，不需要进行环境配置，对新手友好。

代码内容简析

首先可以看这个完整的代码块

头文件

这个部分就是我们常说的头文件

里面的 stdio.h 是编译器中的一个标准库

在这个标准库中包含了包括输入输出在内的一些常见的语句

在头文件中声明这个标准库，就是告诉编译器一会我可能会用到这个标准库里面的语句，你记得先看看这个库里面有什么东西

主函数

这个 main() 函数叫作主函数

在C中，程序的执行顺序是按照主函数内的语句来执行的

主函数对于一段源代码是不可或缺的，我们也是主要在主函数中编写我们的程序

输出

在 stdio.h 这个标准库中包含了printf这个语句，它的作用是输出文本

文本内的内容可以由你自己决定

如果需要换行，就在文本后面加上 \n ，这是表示换行符

切记，当你每写完一个完整的语句后一定要记得加上一个分号;

这个分号必须是英文的分号，中文的没法正常被编译器识别

当你的程序出现无法被编译器识别的地方时，IDE会给你报错，这时候就要仔细检查一下你的代码是否有不规范的地方

返回值

在各个函数中，return 语句用于结束当前函数的执行，把一个值返回给调用者

在主函数中的作用就是结束当前程序的运行

C99 标准规定：如果 main 执行到末尾没有写 return，等价于 return 0;

代码运行

在Dev-C++中，按下键盘上的F9进行编译，会生成一个可执行文件。在编译成功的情况下，按下F10可以运行这个可执行文件。

不过更推荐按F11，因为F11的作用是编译运行，也就是把上面两个步骤一起执行了。

其他

C算是一门很常用的高级编程语言，而且因为比较贴近系统底层，学会了C再去上手其他编程语言（如python、Java）会很容易上手

如果学习过程中发现什么不会的，可以去网上搜一下有没有教程解析

建议在微软的必应搜索引擎中查询，文字教程可以看看博客园，视频教程推荐B站的鹏哥C语言的教程

现在AI也非常聪明，也可以直接把你的代码贴给像DeepSeek等AI，再描述一下你遇到的问题（切记不要照抄AI给的代码，一定要自己动手打一遍）

可以自己在题库网站上照题练习，按照题目要求写完代码可以把代码复制进去提交，推荐使用洛谷，网站左边有一个叫训练题单的分区，按照不同类型列出了一些推荐的练习题，这次可以先试一下B2002 Hello,World!这道题
